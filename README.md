### 📋 CẤU HÌNH SECRETS (BẮT BUỘC)
Vào **Settings → Secrets and variables → Actions** thêm:

| Secret Name | Mô tả |
|-------------|-------|
| `GITHUB_TOKEN` | Tự động có (không cần thêm) |

### 📊 XEM KẾT QUẢ
- **Tab Actions**: Xem lịch sử chạy và logs
- **Artifacts**: Tải bằng chứng và báo cáo
- **README**: Tự động cập nhật trạng thái
